# graceboard-run — собрать прогон (Plan Run) на Доске

Прогон = несколько уже существующих карточек Доски, собранных в один план: DAG
зависимостей, общая ветка `autodev/plan-<id>`, режим `ask`/`auto`. Механика — через
помощник **`~/.claude/bin/gb.mjs`** (см. также скилл **graceboard-card** для создания карточек).

Сервер: `http://127.0.0.1:4317` (локальный, из скилла graceboard-card — тот же).

## Порядок действий

1. **Создай карточки-этапы** (если их ещё нет) — скиллом **graceboard-card**. Каждая карточка
   должна остаться в **Backlog** (не двигай её, не диспатчь) — прогон собирается только из
   недиспатченных карточек в `backlog`/`todo`, не входящих в другой план.

2. **Узнай id карточек:**
   ```bash
   node ~/.claude/bin/gb.mjs board --project <ПРОЕКТ>
   ```

3. **(Опц.) preflight** — проверить, что карточки собираемы:
   ```bash
   node ~/.claude/bin/gb.mjs preflight --project <ПРОЕКТ> --card <id1> --card <id2>
   ```

4. **Собери прогон.** Каждый `--stage` — это `cardId` или `cardId:dep1,dep2` (зависимости —
   id других этапов этого же прогона). Порядок исполнения задаёт DAG зависимостей.
   ```bash
   node ~/.claude/bin/gb.mjs run --project DocsInside2 \
     --goal "Email-уведомления: reset-password + экспорт" \
     --mode ask \
     --stage <idA> \
     --stage <idB>:<idA> \
     --stage <idC>:<idA>
   ```
   Печатает `plan <id>`, ветку и список этапов.

5. **Политика релиза — на входе прогона, не после.**
   `--pr always|never --merge manual|auto --deploy off|after-merge|ask`.
   Не передал → доска возьмёт `deploy_policy` из `.grace/project.md`, затем дефолт
   `always / manual / off`. Красная приёмка не деплоит ни при какой политике;
   боевой стенд (`stand.is_production: true`) всегда требует человека на деплой.
   Флага нет в шапке `head -20 ~/.claude/bin/gb.mjs` → политика не поддержана этой
   версией помощника: держи её текстом в плане, `gb` неизвестные флаги молча глотает.

## Ограничения (проверяются сервером, вернёт 400)

- Только **недиспатченные** карточки в `backlog`/`todo`; уже запущенные нельзя.
- Карточка не должна уже входить в другой план (`planId`).
- Все карточки — одного проекта (`--project`).
- Зависимости не должны образовывать **цикл** (DAG обязан быть ацикличным).
- Хотя бы один `--stage`; без дублей cardId.

## Режимы (`--mode`)
- `ask` (по умолчанию) — на развилках план останавливается и спрашивает человека (§5.3).
- `auto` — агент выбирает сам, но hard-floor всё равно останавливает.

## Гочи по карточкам
Нейминг темы, лимит описания, правило «править только в Backlog» — в скилле **graceboard-card**.
